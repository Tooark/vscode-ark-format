# Release shell1.0.15

## Notes in en-US

### Changes in this version

- Package version bumped from `1.0.14` to `1.0.15`.
- Changelog in English, as suggested in [#24](https://github.com/Tooark/vscode-ark-format/discussions/24):
  - `CHANGELOG.md`, the file shown in the Changelog tab of the Marketplace, Open VSX and VS Code, is now in English, with the full history translated.
  - The Portuguese version moved to `CHANGELOG.pt-BR.md`.
  - Both files have a language switcher at the top, like the READMEs.
- Bilingual release notes: every file in `notes/`, including those of previous versions, now has a section in English (`Notes in en-US`) followed by one in Portuguese (`Notas em pt-BR`), plus a shared section with the tag and the release date.
- No functional changes to the formatting engine and no new settings.

## Notas em pt-BR

### Alterações desta versão

- Versão do pacote atualizada de `1.0.14` para `1.0.15`.
- Changelog em inglês, como sugerido na [#24](https://github.com/Tooark/vscode-ark-format/discussions/24):
  - O `CHANGELOG.md`, arquivo exibido na aba Changelog do Marketplace, do Open VSX e do VS Code, passa a ser em inglês, com todo o histórico traduzido.
  - A versão em português foi movida para `CHANGELOG.pt-BR.md`.
  - Os dois arquivos têm seletor de idioma no topo, como os READMEs.
- Notas de release bilíngues: todos os arquivos em `notes/`, incluindo os das versões anteriores, passam a ter uma seção em inglês (`Notes in en-US`) seguida de uma em português (`Notas em pt-BR`), além de uma seção comum com a tag e a data de lançamento.
- Sem alterações funcionais no motor de formatação e sem novas opções de configuração.
