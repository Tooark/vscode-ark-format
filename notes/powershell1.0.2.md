# Release powershell1.0.2

## Notes in en-US

### Changes in this version

- Version bump of the `ark-format-powershell` package: `1.0.1` -> `1.0.2`.
- VS Code integration fix so that coloring/syntax highlighting is not affected:
  - Removed the `contributes.languages` block from the package manifest.
  - Avoids overriding the association of the `.ps1`, `.psm1` and `.psd1` extensions without a grammar of its own.

## Notas em pt-BR

### Alterações desta versão

- Bump de versão do pacote `ark-format-powershell`: `1.0.1` -> `1.0.2`.
- Correção de integração com o VS Code para não afetar a coloração/syntax highlighting:
  - Removido o bloco `contributes.languages` do manifesto do pacote.
  - Evita sobrescrever associação de extensões `.ps1`, `.psm1` e `.psd1` sem grammar própria.
