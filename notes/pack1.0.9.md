# Release pack1.0.9

## Notes in en-US

### Changes in this version

- Version bump of the `ark-format` package: `1.0.8` -> `1.0.9`.
- Extension pack aligned with the security maintenance round of the formatter packages:
  - `ark-format-shell` with vulnerable dependencies updated (Dependabot alerts).
  - `ark-format-powershell` with vulnerable dependencies updated (Dependabot alerts).
- Workspace build/test dependencies updated: `esbuild` (`0.28.1`), `vite` (`>=8.0.16`), `undici` (`>=7.28.0`), `markdown-it` (`>=14.2.0`), `tmp` (`>=0.2.7`) and `form-data` (`>=4.0.6`).
- No extension pack configuration changes beyond the release alignment.
