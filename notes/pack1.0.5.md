# Release pack1.0.5

## Notes in en-US

### Changes in this version

- Version bump of the `ark-format` package: `1.0.4` -> `1.0.5`.
- Complete restructuring of the extension pack README to the new documentation standard:
  - Added version/download (Open VSX) and license badges.
  - Sections reorganized into a standardized flow (`Features`, `Getting Started`, `Included Extensions`, `How to Use`, `Which One Should You Install?`, `Tips & Best Practices`).
  - Improved presentation of the install links (VS Marketplace and Open VSX) for the included extensions.
- Added Brazilian Portuguese documentation to the package:
  - Created `README.pt-BR.md` with content equivalent to the main README.
  - Added language navigation between the EN and PT-BR READMEs.
- Package description aligned with the purpose of the extension pack (installing Shell + PowerShell together).
- Created a `CHANGELOG.md` file to record changes to the pack package.
