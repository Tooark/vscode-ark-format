# Release pack1.0.0

## Notes in en-US

First version of **Ark Format** — the extension pack that brings together all the formatters of the Ark Format family in a single install.

### What's included

This package automatically installs the following extensions:

| Extension                  | Description                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Ark Format: Shell**      | Formatting for Shell scripts (.sh, .bash, .zsh, .ksh, .tcsh, .azcli, .bats) with optional shfmt integration |
| **Ark Format: PowerShell** | Formatting for PowerShell scripts (.ps1, .psm1, .psd1) with smart indentation of param blocks               |

### Combined Features

- Smart formatting — full documents or partial selections
- Independent settings per language
- Multi-language UI (EN and PT-BR)
- .editorconfig integration
- Optional shfmt integration for Shell
- `param()` block indentation in PowerShell
- Lightweight and fast — no required external dependencies

### When to use this package

| Scenario                                 | Recommended extension         |
| ---------------------------------------- | ----------------------------- |
| You only work with Shell                 | Ark Format: Shell             |
| You only work with PowerShell            | Ark Format: PowerShell        |
| You work with both or want full coverage | **Ark Format** (this package) |
