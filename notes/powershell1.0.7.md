# Release powershell1.0.7

## Notes in en-US

### Changes in this version

- Version bump of the `ark-format-powershell` package: `1.0.6` -> `1.0.7`.
- Removed the activation log (`ark.active`) to reduce noise in the extension host.
- Publishing pipeline adjusted to avoid passing the token explicitly on the command line (`vsce` and `ovsx`).
- Operational security improvement in CI, reducing secret exposure during the publish process.

## Notas em pt-BR

### Alterações desta versão

- Bump de versão do pacote `ark-format-powershell`: `1.0.6` -> `1.0.7`.
- Remoção de log de ativação (`ark.active`) para reduzir ruído no host da extensão.
- Ajuste no pipeline de publicação para evitar passagem explícita de token em linha de comando (`vsce` e `ovsx`).
- Melhoria de segurança operacional no CI, reduzindo exposição de segredos no processo de publish.
