# Release shell1.0.5

## Notes in en-US

### Changes in this version

- Version bump of the `ark-format-shell` package: `1.0.4` -> `1.0.5`.
- Complete restructuring of the package documentation to the new README standard:
  - added version/download (Open VSX) and license badges.
  - sections reorganized into a standardized flow (`Features`, `Getting Started`, `How to Use`, `Supported File Types`, `Configuration`, `Tips & Best Practices`).
  - consistency adjustments to headings, examples and usage text.
- Added Brazilian Portuguese documentation to the package:
  - created `README.pt-BR.md` with content equivalent to the main README.
  - added language navigation between the EN and PT-BR READMEs.
- Configuration consistency fixes in the documentation:
  - `lineEnding` aligned to `LF` in the main example, matching the extension default.
  - fixed the usage tip to reference Shell files (instead of PowerShell).
- Created the `CHANGELOG.md` file to record changes in the shell package.
