# Release shell1.0.10

## Notes in en-US

### Changes in this version

- Version bump of the `ark-format-shell` package: `1.0.9` -> `1.0.10`.
- Extension description on the Marketplace updated (`package.nls.json` and `package.nls.pt-br.json`) to:
  - clearly reflect support for Shell file types (`.sh`, `.bash`, `.bats`, `.zsh`);
  - explicitly state support for the `internal` (built-in) and `shfmt` formatting engines.
- No changes to the formatting engine's behavior; the change focuses on clearer communication and package documentation.

## Notas em pt-BR

- Bump de versão do pacote `ark-format-shell`: `1.0.9` -> `1.0.10`.
- Atualização da descrição da extensão no Marketplace (`package.nls.json` e `package.nls.pt-br.json`) para:
  - refletir claramente o suporte aos tipos de arquivo Shell (`.sh`, `.bash`, `.bats`, `.zsh`);

- Sem alterações no comportamento do motor de formatação; mudança focada em clareza de comunicação e documentação do pacote.
